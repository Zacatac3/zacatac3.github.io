Title: 1.2 – 2/23/26

Description: Under the Hood Improvements & New Game Update contents

Heading: New Features & Additions
- Images can now be displayed directly in the Changelog
- Overall, the app should now run much smoother, code has been rebuilt from ground up, to continue scaling the app up. Previous code was getting bloated due to not expecting the app to reach this size
- Individual equipment can now be hidden from the equipment tab 
- iPad layout now supports two columns to better use screen real estate, optional toggle for "Legacy Layout"
- Boosts can now be customized, allowing them to be applied immediately or for a custom duration
- Simplified settings menu, with grouping of settings into sub menus
- Added options to lock screen widgets for closest overall upgrades in home village and builder base
- Added support for new game update content, including dragon duke (and equipment), new building/troop levels, and Greedy Raven

Heading: Changes and Fixes
*Changes and Fixes*
- Profile page should no longer briefly freeze the app, and it's loading has been optimized
- Profile selectors when customizing widgets now display actual profile names
- War Card now tells you when your clan's war log is set to private
- pop up indicating empty clipboard when importing
- some assets were previosuly showing up very small, this should be resolved
- star lab assets should now properly display on the builder base widget
- notifications should now always use Player profile name instead or Profile tag
- Images now work properly on clear and tinted widgets
- Helpers, pet potions now only show up in boosts menu once they are unlocked
- Factory reset now resets show/hide status and resets order of cards
- added option to review app from within settings
- added new option to reset layouts
- Town hall 18 now shows the correct number of walls that can be upgraded to max
- Inferno artillery support added, previously acted like town hall upgrade
- App website visual update
